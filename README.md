# orleanss777-sys.github.io

Landing page profissional de **Orleans Samai** — Analista de Suporte Técnico N2 em transição
para Cloud Network Engineering.

🔗 **Acesse:** https://orleanss777-sys.github.io

## Sobre

Página estática de arquivo único (`index.html`), sem build e sem dependências:
HTML + CSS + um pouco de JavaScript puro. Publicada via **GitHub Pages** a partir do branch `main`.

Seções: apresentação, princípios de trabalho, stack técnica, projetos em destaque,
estudos em andamento e contato.

## Rodar localmente

Basta abrir o `index.html` no navegador — ou servir a pasta:

```bash
python -m http.server 8080
```

## Estrutura

```
.

```
